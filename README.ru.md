# Единомышленники

Веб-приложение для поиска компании: пользователи публикуют мероприятия (кино, прогулка, настольные игры…), остальные записываются на них.

Проект начинался как дипломная работа на PHP со страницами, которые строит сервер. Интерфейс я переписал на **React** (одностраничное приложение), а PHP-часть превратил в **JSON API**. Старая версия на PHP сохранена в истории Git (тег `php-legacy`).

Подробное описание, структура проекта, список запросов API и инструкция по запуску: [README.md](README.md) (на английском).

## Быстрый запуск

1. Создайте базу `club` и импортируйте `database/club.sql`.
2. Скопируйте `config/db_params.example.php` в `config/db_params.php` и впишите данные доступа к базе.
3. Запустите PHP-сервер (OpenServer, XAMPP) так, чтобы работал адрес `http://friends/api/events`.
4. В папке `frontend` выполните `npm install`, затем `npm run dev` и откройте http://localhost:5173.

Тестовые входы (только для разработки): `admin` / `admin` и `user` / `user`.
